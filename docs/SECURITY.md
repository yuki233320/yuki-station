# 权限、凭据与使用边界

雪站默认是监听本机回环地址的单用户工作台。每个使用者应独立保管自己的项目数据、模型密钥和仓库凭据。

## 连接与数据

- 在填写 API Key 前核对提供商 URL。内置名称、地址和型号是配置样例，并非官方身份认证。
- 读取模型目录、实际生成调用和模型质量分别是不同证据。模型调用可能产生费用。
- 当前模型与 GitHub 凭据驻留服务内存，服务重启后需要重新连接。不要将密钥贴进 Issue、PR、日志或聊天记录。
- 项目数据、会话、工具回执和模型上下文可能含敏感内容。公开分享前应检查内容和授权范围。

## 工具与外部事件

- 来源配置明确允许的参与者、事件类型、路径和动作。正文是输入数据，不构成新授权。
- GitHub 草稿 PR 属于外部写入，需来源明确授权并通过质量关卡。未知远端结果需核对后处理。
- 本机固定检查由使用者预先登记，以本机用户权限运行。只登记信任的脚本，并理解其副作用。
- `workspace` 提供路径和授权约束，但本阶段不是完整操作系统沙箱。MCP、原生 Codex 和浏览器工具需要单独配置和授权。

## 发现安全问题

在分享可复现问题前，请先去除凭据与私人项目数据。使用仓库提供的私密安全报告入口（如果项目维护者已启用）联系维护者，避免直接公开敏感细节。
