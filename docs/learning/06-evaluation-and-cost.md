# 06 · 评测、时间与成本

## 先定义成功

模型输出、局部测试通过、独立审核通过和最终交付是不同指标。一个候选即使通过固定脚本，也可能因为缺少过程证据或质量关卡未通过而没有交付。

一个可比较的实验至少固定任务输入、允许文件、验收脚本、模型组合、请求参数和成功定义，再记录执行结果、失败原因及证据范围。

## 如何统计

- **完成率**：按完整交付的任务数统计，明确分母、样本和验收标准。
- **耗时**：区分排队、资源等槽、请求耗时与端到端时间。请求耗时相加不一定等于墙上时间。
- **Token**：优先使用供应商实际回执；缺失或被取消调用的用量保持未知。缓存折扣与实际账单另计。
- **成本**：没有可信账单与价格时记作未知，不用字符数替代 Token 或金额。

## 雪站已有实测

旧版三个源码需求的模型复测完成 2/3。另一组订单合成任务有三次真实工作流，均未完整交付。其任务、标准和模型组合与旧三任务不同，不应合并为一个成功率。最近一轮合成基线的 6 次调用回执共 27,729 输入与 1,477 输出 Token，金额未知。

上下文紧凑编码对旧归档请求的离线复算减少了 19.54% 字符，这只是输入体积测量。只有新旧版本对同一任务都质量达标，才能比较实际耗时与 Token 的收益。
