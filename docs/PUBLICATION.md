# 源码公开范围

本仓库首次发布基于雪站 0.2.8（12）源码白名单。公开内容包括服务端、Web 界面、测试、可选 Codex 与 MCP 桥接源码、macOS 原生窗口源码、项目文档及学习材料。

发布快照经以下处理：

- 移除个人协作入口文件和内部开发归档；公开的架构、状态和使用文档按当前实现重写。
- 两个测试中的私人仓库标识替换为公开示例，架构审查模板使用通用项目名称。
- 不纳入本机项目、会话与执行回执、SQLite 数据、模型注册、模型或 GitHub 密钥、依赖安装目录及本机桌面绑定。
- `desktop/macos` 保留构建源码、图标、运行时来源和许可证，不提交运行时归档或应用二进制。
- 保留已创建仓库时选择的 MIT 许可证，代码目录中的现有许可证和第三方素材许可证各自保留。

公开快照对报告模板文字和源码白名单做了少量整理，因此其源码指纹与个人机器上的已安装版本不同。运行前请阅读[使用与开发](GETTING_STARTED.md)和[安全与权限](SECURITY.md)。

后续同步应以正式桌面版本和源码镜像一致为起点，使用发布白名单并对新增内容做隐私检查。仓库中的 README、学习材料和状态文档属于需要维护的公开内容。
