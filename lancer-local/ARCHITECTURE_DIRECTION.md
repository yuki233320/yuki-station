# 雪站架构方向

本文件是源码包中的简短入口。完整项目构想、分层与上游参考见[仓库 README](../README.md) 和 [开源项目对比](../docs/COMPARISON.md)。

雪站保留项目、岗位、冻结任务合同、真实工具回执、逐项验收、依赖修复、幂等交付、角色记忆和回放。任务状态由会话 SQLite 管理，Trigger 事件、订阅与外部效果单独持久化。新增能力必须保持真实执行、模型判断和最终交付的事实边界。

事件来源通过规则过滤、授权研判和派工进入工作台。已认领的同串反馈在授权范围内交给原 Worker。实际状态、已验证范围与后续计划分别见[状态](../docs/STATUS.md)和[路线图](../docs/ROADMAP.md)。
