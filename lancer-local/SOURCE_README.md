# 雪站源码说明

从仓库根目录查看 [README](../README.md)、[使用与开发](../docs/GETTING_STARTED.md) 和 [当前状态](../docs/STATUS.md)。普通本机工作台从本目录执行 `python3 app.py --data-dir ./workspace-data --port 8767`，然后访问 `http://127.0.0.1:8767/studio`。

公开源码以 0.2.8 为基线。各人的模型、凭据、项目和工具授权需要在各自环境中配置。固定检查脚本以本机用户权限运行；请只登记可信脚本。可选 MCP 和原生 Codex 桥接需要另外配置。
