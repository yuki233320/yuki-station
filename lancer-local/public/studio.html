协作量化对照

原工作流对照每次重复都新建两组隔离项目，真实调用你的模型 API 并产生费用；重复次数会相应增加双臂调用。这不是对当前项目源码的审查。仅复制项目中配置的岗位规范，不复制岗位文件、项目源码或历史业务记忆。通过率不是生产力总分。

原工作流：订单和资料案例需要主模型外至少一个文本 API 成员，复杂开发需要至少两个；均不使用原生执行器或图像模型。开发源码由宿主运行验收。请先在工作小组中保存相应配置，执行结果可手动刷新查看。

SAS / MAS 交付对照

SAS：一位智能体、一个上下文直接交付。MAS：规划、两位岗位执行者、汇总；共四次调用。使用相同任务与固定验收器；不设任务总额度，不按阶段分摊，保留实际用量。这是独立实验，不修改项目源码或生产编排。

每次请求沿用模型协议的单次技术参数；供应商仍可能有上下文、输出或账户限制。本实验未控制计算预算，不作为等预算优势证据。费用由用户按提供商账单判断。
